# NexyDAO

Autonomous AI Investment Company

## Objective
Operate an AI-managed investment company with
$5,000 initial simulated capital.

Target: 15% annual net return.

## Architecture
- AI CEO
- Research agents
- Portfolio manager
- Independent risk officer
- Investment committee
- Auditor
- IBKR paper trading

## Infrastructure
Google Cloud Ubuntu 24.04 LTS
Python 3.12
OpenAI API

## Safety
Paper trading only during development.
No real-money execution.
Independent review of investment decisions.
Protected working capital.
